# 0 · Start here

BloomIndex is a literature RAG + NER + paper-reader workbench for
phytochemistry, ethnobotany and natural-product chemistry.

- **Explore** (`/`) — search Europe PMC / OpenAlex, dashboard over the SQLite KB.
- **Analyse** (`/analyse`) — upload PDFs, extract entities, compare papers.
- **Chat** (`/chat`) — ask questions over your uploaded PDFs, cited answers.
- **Paper** (`/paper/$doi`) — full-text reader with entity highlighting + graph.

Five-minute path: [1-install](../1-install/index.md) → open
http://localhost:5173 → search `eugenol` → open a paper → press `E`.
